## 3. 本次发布（0.0.1 / 构建 53）内容

**武器内容包（`weapons_mechanoid_launchers`）**

- 五把回收机械族发射器：`Latios_BL66_Thermal`、`Latios_BL80_Fuel`、`Latios_HL66_Thermal`、`Latios_HL80_Fuel`、`Latios_HL164_Demo`。
- 复用 Combat Extended 的机械族重型弹药（66mm 热能弹 / 80x256mm 燃料弹 / 164x284mm 爆破弹），无需额外弹药生产线。
- BL 逐发装填（6 / 3 发），HL 整弹匣更换（6 / 3 / 2 发，单次更慢）。
- 高抛模式（逐武器切换）：越过墙体与屋顶，弹速 ×0.6，落点以目标为圆心的圆形散布；瞄准与冷却 BL ×1.5 / HL ×1.2，散布增长 BL 0.07/格 / HL 0.05/格。
- 高抛有效射程按弹头弹道上限夹紧，射程加成不会产生打不到的射击。
- 研究：无托 = 基础机械科技 + 精密装配；肩扛 = 高级机械科技 + 精密装配；均在精密装配台制作。

**医疗内容包（`medical_biofoam`）**

- `Latios_BiofoamInjector`：腰带装备，4 次充能；流血速度超过 100% 时消耗 1 次充能，以固定 75% 包扎质量封住最严重的出血伤口。
- 装填作业：走过去/取随身医药 + 数秒装填，1 份医药恢复 2 次充能；可开关自动装填（绿勾/红叉）。
- 研究「医药生产」后在机械加工台制作。

**内容包机制**

- 开关在 Def 载入前生效，关闭的内容包不进入游戏；改动需重启；存档记录内容包快照并在载入时提示差异。

## 5. 致谢与来源声明（发布页一致口径）

- 武器线（机械族回收发射器）的**设计思路与枪械外观风格**参考 **Local's CE Mechscav guns**；未使用该模组任何素材拼接/修改，未做人工智能图像到图像（i2i）处理；建议玩家尝试 Local's CE 系列模组。
- Combat Extended：弹药、弹头行为与机械族武器基准；Harmony：补丁框架。
- 所有美术素材由作者制作；本次发布的功能均由作者在真实殖民地中充分测试。
- 开发使用 **DS v4.1 flash** 与 **DSH**；构建/部署/自动化测试流程基于 **RimDevTools**（https://github.com/1264600905/RimDevTools）。

## 6. 已知限制（发布页可保留，也可只在评论里回答）

- 只能在 1.7 + Combat Extended 环境运行，缺失 CE 时武器内容包无法使用。
- 内容包开关的改动必须重启游戏才生效（Def 在载入期决定）。
- 高抛弹道是 CE 的 overhead 弹道，会忽略屋顶与墙体遮挡；这是机制设计而非 bug。
- 高抛散布为圆形，落点可能落在目标周围 1~8 格内（随距离线性增长，见 `策划案/武器参数表.md`）。
